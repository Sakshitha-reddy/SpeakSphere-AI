# SpeakSphere AI

## 🚀 Overview

SpeakSphere AI is an AI-powered English learning platform that helps users improve their spoken English through AI conversations and live voice calls with other learners.

---

## 🌟 Features

- 🤖 AI English Tutor
- 🎤 AI Voice Conversation
- 👥 Live Voice Calls with Learners
- 📚 Grammar Correction
- 🗣 Pronunciation Feedback
- 📈 Progress Dashboard
- 🎯 Interview Preparation
- 🔥 Daily Speaking Challenges
- 💎 Premium Membership

---

## 🛠 Tech Stack

- React
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Firebase Authentication
- WebRTC
- OpenAI API
